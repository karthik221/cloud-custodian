You are a Principal AWS Solutions Architect, FinOps Architect, and Senior Python Engineer.

Design and implement a production-ready AWS Lambda Rightsizing and Cost Optimization platform.

## Objective

Analyze AWS Lambda execution history over configurable historical periods (90, 180, 270, and 365 days) to identify memory optimization opportunities and estimate monthly and annual cost savings while maintaining application performance.

The recommendations must be evidence-based using historical CloudWatch data.

## Input

The application accepts a CSV file containing:

AWS Profile
AWS Account ID
AWS Region
Lambda Function Name

The environment already has multiple AWS CLI named profiles configured.

The application must authenticate using boto3.Session(profile_name=...) instead of AssumeRole.

## Data Collection

For every Lambda:

Retrieve configuration:

- Memory Size
- Runtime
- Architecture
- Timeout
- Ephemeral Storage
- Reserved Concurrency
- Provisioned Concurrency

Retrieve CloudWatch Metrics:

- Invocations
- Duration
- Errors
- Throttles
- Concurrent Executions

Retrieve CloudWatch Logs using CloudWatch Logs Insights.

Parse REPORT log entries to extract:

- Duration
- Billed Duration
- Memory Size
- Max Memory Used
- Init Duration

Compute:

- Average Memory Used
- Maximum Memory Used
- P95 Memory Used
- P99 Memory Used
- Average Duration
- Maximum Duration
- Average Init Duration
- Total Executions

If Lambda Insights is enabled, retrieve:

- Average CPU utilization
- Peak CPU utilization
- Average Memory utilization
- Peak Memory utilization

Retrieve Cost Explorer data:

- Monthly Lambda cost
- Historical cost
- Cost trend

## Analytics

For every Lambda calculate:

- Average memory utilization
- P95 memory utilization
- Maximum memory utilization
- Average CPU utilization
- Peak CPU utilization
- Average execution duration
- Invocation trends
- Cold start frequency

Determine:

- Over-provisioned Lambdas
- Under-provisioned Lambdas
- Idle Lambdas
- Cold-start candidates

## Recommendation Engine

Recommend optimal memory allocation using:

Configured Memory

Historical P95 Memory

Peak Memory

CPU utilization

Execution duration

Use a configurable safety factor (default 1.3x above P95 memory usage).

Estimate new execution duration after memory adjustment and ensure the projected duration remains within the configured SLA.

Calculate:

- Current monthly cost
- Projected monthly cost
- Monthly savings
- Annual savings
- Optimization percentage

Assign a confidence score:

High
Medium
Low

based on workload stability and historical variance.
